# Отклик

Живые опросы для выступлений: спикер показывает вопрос и QR-код, зрители отвечают с телефона, ответы появляются на экране примерно через секунду. Аналог Mentimeter и AhaSlides, который ставится на свой хостинг.

Участникам не нужны приложения и регистрация. Сервис рассчитан на 300 одновременных участников на обычном виртуальном хостинге.

## Возможности

**Одиннадцать типов слайдов:** открытый ответ, облако слов, опрос (один или несколько вариантов, с картинками), викторина с таймером и очками, шкала, ранжирование, «угадай число», точка на картинке, вопросы спикеру с лайками, информационный слайд, обратная связь с индексом NPS.

**Ведение сессии:** пульт отдельно от экрана, имена и проверка ответов до показа по желанию спикера, фильтр стоп-слов, скрытие результатов до закрытия голосования, вывод одного ответа на весь экран, сравнение «до и после», срез опроса по ответу на другой опрос, реакции-эмодзи, счётчики участников, горячие клавиши, звук таймера.

**Кабинет спикера:** редактор слайдов, шаблоны, импорт вопросов из текста или таблицы, темы оформления с логотипом и фоном, самостоятельный режим прохождения по ссылке, итоговый отчёт для печати в PDF, экспорт в CSV, архив, ссылка для вставки экрана в презентацию.

**Аккаунты и админка:** регистрация с подтверждением почты, сброс пароля, роли спикера и администратора, управление пользователями, статистика, режим регистрации (открытая, по приглашению, закрытая).

## Как это устроено

- PHP 8 и SQLite, без фреймворков, сборки и фоновых процессов.
- Телефоны раз в две секунды читают маленький файл `public/state/<код>.json`. Его отдаёт веб-сервер напрямую, PHP при этом не запускается, поэтому сотни ожидающих участников почти не создают нагрузки.
- PHP вызывается, когда участник отправляет ответ, и для экрана с пультом, которые раз в секунду запрашивают сводку.
- Интерфейс написан на чистом JavaScript. Шрифты Golos Text и Unbounded лежат в `public/assets/fonts`, внешних запросов страницы не делают.

```
bin/            служебные скрипты: проверка окружения, нагрузочный тест
docs/           инструкция по установке
public/         корень сайта: страницы, api.php, стили и скрипты
  state/        состояния сессий для телефонов (создаются сами)
  uploads/      загруженные картинки
src/            серверный код, недоступен из интернета
storage/        база и журнал писем, недоступны из интернета
```

## Быстрый запуск на своём компьютере

Нужен PHP 8.0 или новее с расширениями `pdo_sqlite`, `mbstring`, `fileinfo`.

```bash
php -S localhost:8000 -t public
```

Откройте `http://localhost:8000` и зарегистрируйтесь. Первый аккаунт становится администратором. Письма в этом режиме не отправляются, а пишутся в `storage/logs/mail.log`.

Чтобы проверить окружение и права на папки:

```bash
php bin/migrate.php
```

## Нагрузочная проверка

Откройте на пульте слайд с опросом и запустите:

```bash
php bin/loadtest.php https://ваш-сайт.ru 123456 300
```

Скрипт одновременно подключит 300 участников, отправит их ответы и покажет, сколько из них учтено.
