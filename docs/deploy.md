# Установка на Beget

Инструкция для виртуального хостинга Beget с доступом по SSH. На другом хостинге шаги те же, отличаются только пути.

## Что понадобится

- сайт в панели Beget с привязанным доменом и включённым SSL-сертификатом;
- PHP 8.0 или новее для этого сайта (панель → «Сайты» → настройки сайта → версия PHP);
- включённый доступ по SSH (панель → «SSH»);
- репозиторий с кодом на GitHub.

Ниже `LOGIN` — ваш логин на Beget, `example.ru` — папка сайта. Замените их своими.

## 1. Подключитесь по SSH

```bash
ssh LOGIN@LOGIN.beget.tech
```

На Beget команды PHP и git выполняются внутри окружения сайта. Войдите в него:

```bash
ssh localhost -p222
```

## 2. Скачайте код

Код кладётся рядом с папкой `public_html`, а не внутрь неё: так база и настройки остаются недоступны из интернета.

```bash
cd ~/example.ru
git clone https://github.com/ВАШ_АККАУНТ/otklik.git app
```

## 3. Направьте сайт на папку public

Сохраните старую папку и замените её ссылкой на `app/public`:

```bash
cd ~/example.ru
mv public_html public_html.old
ln -s app/public public_html
```

### Вариант без ссылки

Если заменить `public_html` ссылкой нельзя, разложите файлы так: всё, кроме папки `public`, — в папку сайта рядом с `public_html`, а содержимое `public` — внутрь `public_html`. Сервис сам найдёт корень сайта под именем `public_html`. Стандартную страницу Beget `public_html/index.php` при этом нужно убрать, иначе она откроется вместо главной.

```
~/example.ru/
  src/  bin/  storage/  config.php
  public_html/   ← содержимое папки public
```

## 4. Создайте настройки

```bash
cd ~/example.ru/app
cp config.example.php config.php
nano config.php
```

Что изменить:

| Параметр | Значение |
|---|---|
| `app_url` | адрес сайта, например `https://example.ru` |
| `mail_from` | существующий почтовый ящик на вашем домене, например `noreply@example.ru` |
| `mail_to_log` | `false`, чтобы письма отправлялись |

## 5. Проверьте окружение

```bash
php bin/migrate.php
```

Скрипт создаст базу и покажет, есть ли права на запись и нужные расширения PHP. Если в списке есть «НЕТ ПРАВ НА ЗАПИСЬ», выполните:

```bash
chmod 775 storage public/state public/uploads
```

Если команда `php` запускает старую версию, вызовите нужную явно, например `php8.2 bin/migrate.php`.

## 6. Создайте администратора

Откройте сайт в браузере и зарегистрируйтесь. Первый аккаунт получает права администратора и не требует подтверждения почты.

После этого в админке → «Настройки» выберите, кто может регистрироваться: все, только по приглашению или никто.

## 7. Проверьте с телефона

1. Создайте сессию из шаблона «Знакомство с аудиторией».
2. Нажмите «Перейти к ведению», затем «Открыть большой экран».
3. Отсканируйте QR-код телефоном через мобильный интернет, а не Wi-Fi: так вы проверите доступ снаружи.
4. Запустите первый слайд и ответьте.

## Чтобы письма не попадали в спам

В панели Beget создайте ящик, указанный в `mail_from`, и включите для домена записи SPF и DKIM (панель → «Почта» → настройки домена). Без них письма с подтверждением и сбросом пароля часто уходят в спам.

Пока почта не настроена, администратор может подтвердить адрес пользователя вручную: админка → «Пользователи» → «Подтвердить почту».

## Большой словарь стоп-слов

Встроенный список короткий. Готовый словарь подключается двумя способами:

- админка → «Настройки» → «Загрузить список из файла .txt» (до 250 КБ), затем «Сохранить настройки»;
- файл `storage/stopwords.txt` на сервере: одна основа слова на строку, строки с `#` — комментарии. Размер не ограничен, файл подхватывается сразу.

Ответ скрывается, если какое-то слово в нём начинается с основы из списка. Основы короче трёх букв пропускаются.

## Обновление

```bash
cd ~/example.ru/app
git pull
```

Таблицы базы обновятся сами при первом запросе.

## Резервная копия

Все данные лежат в двух местах: файл `storage/app.sqlite` и папка `public/uploads`. Скопируйте их:

```bash
cd ~/example.ru/app
sqlite3 storage/app.sqlite ".backup storage/backup-$(date +%F).sqlite"
tar czf ~/otklik-uploads-$(date +%F).tar.gz public/uploads
```

Если команды `sqlite3` нет, остановите активные сессии и скопируйте файлы `storage/app.sqlite*` целиком.

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Белая страница или ошибка 500 | Версию PHP сайта и вывод `php bin/migrate.php` |
| Телефон пишет «Сессия не найдена» | Права на запись в `public/state` |
| Картинки не загружаются | Права на `public/uploads` и лимит размера в админке |
| QR-код ведёт на неверный адрес | Параметр `app_url` в `config.php` |
| Не приходят письма | `mail_to_log` равен `false`, ящик `mail_from` существует, SPF и DKIM включены |
| Телефоны не переключают слайды | Что файл `https://example.ru/state/КОД.json` открывается в браузере |
